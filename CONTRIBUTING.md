# Contributing to Lean Code OSS

Welcome, and thank you for your interest in contributing to Lean Code OSS!

Lean Code OSS is a public downstream of Code - OSS focused on the small, instant, keyboard-centered editor experience.
Our development processes are governed by the Black Hole protocol.

## Upstream Attribution

Lean Code OSS is a fork of Microsoft's VS Code (Code - OSS). We appreciate the tremendous work done by the upstream maintainers.
However, since this is a separate downstream project, please **do not** file issues or pull requests for Lean Code OSS in the upstream Microsoft repository.

## Reporting Issues and Feature Requests

All development, issue tracking, and contributions for Lean Code OSS are managed internally via Jules.
If you have identified a reproducible problem or have a feature request, please submit your feedback directly to Jules.

## Pull Requests

Contributions are autonomous and managed under the Black Hole protocol. Pull requests are created and reviewed by Jules based on planned work orders. Manual external contributions are typically handled by submitting your intent or issue to Jules, who will schedule the work if it aligns with the project vision.

## Thank You

Thank you for taking the time to understand our autonomous development boundaries and for your interest in Lean Code OSS.
