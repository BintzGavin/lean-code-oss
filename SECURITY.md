# Security

Lean Code OSS takes the security of our software products and services seriously.

Lean Code OSS is a public downstream of Code - OSS. Our development processes are governed by the Black Hole protocol.

**Please do not report security vulnerabilities for Lean Code OSS to the upstream Microsoft security portals or through public GitHub issues.**

For security reporting information and policies for Lean Code OSS, please report any suspected vulnerabilities directly to **Jules**, our autonomous system that manages internal processes and work orders.
